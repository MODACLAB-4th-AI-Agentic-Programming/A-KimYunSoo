# 2026-05-03 작업 일지

## 오늘 한 것: Blinn-Phong 조명 모델 적용

### 배경

기존 Lambert 조명 모델에서는 난반사(diffuse)만 계산되어 광택이 있는 표면 표현이 불가능했다. Blinn-Phong 스페큘러 반사를 추가해 보다 사실적인 조명을 구현했다.

---

### 변경 사항

#### 1. `cbPerObject` 상수 버퍼 구조체 수정 (`D3DApp.h`)

- `specPower` 필드 추가
- `lightDir`와 `usePOM` 필드 순서 재정렬
- 명시적 패딩(`pad[3]`) 추가로 16바이트 정렬 보장
- 구조체 크기: 224 → 240 bytes

**HLSL 상수 버퍼는 16바이트 단위로 정렬되어야 하므로, CPU 구조체도 이에 맞춰 레이아웃을 맞춰야 한다.**

```cpp
struct cbPerObject
{
    XMMATRIX world;
    XMMATRIX view;
    XMMATRIX proj;
    XMFLOAT3 cameraPos;   // block [192-207]
    float    heightScale;
    XMFLOAT3 lightDir;    // block [208-223]
    float    specPower;
    int      usePOM;      // block [224-239]
    int      pad[3];
};
```

#### 2. `D3DApp.cpp` 수정

- 상수 버퍼 업데이트 시 `specPower` 값 전달 추가
- ImGui에 **Specular Power** 슬라이더 추가 (범위: 1.0 ~ 256.0, 기본값: 32.0)

#### 3. `POM_PS.hlsl` - 픽셀 셰이더 조명 모델 업그레이드

Lambert 단일 조명에서 **Blinn-Phong** 조명 모델로 전환했다.

**이전 (Lambert only):**
```hlsl
float  NdotL = saturate(dot(normalWS, normalize(gLightDir)));
float3 lit   = diffuse.rgb * (NdotL * 0.85 + 0.15);
```

**이후 (Blinn-Phong):**
```hlsl
float3 L = normalize(gLightDir);
float NdotL = saturate(dot(normalWS, L));

// Half-vector 기반 스페큘러
float3 H    = normalize(viewDirWS + L);
float NdotH = saturate(dot(normalWS, H));
float spec  = pow(NdotH, gSpecPower);

float3 lit = diffuse.rgb * (NdotL * 0.85 + 0.15)
           + float3(1.0, 1.0, 1.0) * spec * 0.6 * NdotL;
```

**Blinn-Phong vs Phong:** Half-vector(H)를 사용하므로 반사 벡터(R)를 계산하는 Phong보다 연산량이 적고, 시야각이 클 때 더 자연스러운 결과를 낸다. `NdotL`을 곱해 빛이 닿지 않는 면에는 스페큘러가 생기지 않도록 마스킹했다.

---

### 결과

- ImGui 슬라이더로 Specular Power를 실시간으로 조절 가능
- 값이 낮을수록 넓고 부드러운 광택, 높을수록 좁고 날카로운 하이라이트
